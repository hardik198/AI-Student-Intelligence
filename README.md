# 🎓 AI Student Success & Career Intelligence System

An end-to-end Data Science and Machine Learning project that predicts student academic outcomes and provides career skill-gap analysis with a personalized learning roadmap.

## 🚀 Project Features

- 📊 Exploratory Data Analysis
- 🧹 Data preprocessing
- ⚙️ Feature engineering
- 🌲 Random Forest classification
- 🔧 Hyperparameter tuning
- 🎯 Student outcome prediction
- 📈 Model evaluation
- 💼 Career skill-gap analysis
- 🛣️ Personalized learning roadmap
- 🖥️ Interactive Streamlit dashboard

## 🎯 Student Outcome Prediction

The machine learning model predicts one of three outcomes:

- Dropout
- Enrolled
- Graduate

## 🤖 Machine Learning

The project uses a Random Forest Classifier.

Feature engineering includes:

- Semester 1 approval rate
- Semester 2 approval rate
- Average approval rate

### Evaluation Metrics

The model is evaluated using:

- Accuracy
- Macro F1 Score
- Precision
- Recall
- Confusion Matrix
- Feature Importance

## 💼 Career Intelligence

The application compares a student's current skills with skills required for different career paths.

Supported career paths:

- Data Scientist
- Data Analyst
- Machine Learning Engineer
- Web Developer

The system identifies:

- Matched skills
- Missing skills
- Skill match percentage

## 🛣️ Personalized Roadmap
